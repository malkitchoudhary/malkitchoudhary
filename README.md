### Hi, I'm Malkit Choudhary — Data Science & ML Engineer, Jaipur 👋

I build machine learning systems the way an engineer builds infrastructure — not to make a notebook run once, but to make it survive real, messy data. Currently finishing my **BCA at Manipal University Jaipur** while training in **Data Science & Machine Learning at Tips-G (RNS IT Solution)**.

My work lives in the overlap of **NLP and recommendation systems** — resume-to-job matching, paper recommendation, movie recommenders served through FastAPI. Right now I'm pushing into **Transformer internals and multimodal AI**, and competing on Kaggle because real datasets break your assumptions in ways clean tutorials never do.

> 🧠 *Mindset: debug first, believe metrics second.*

### Things I've built

| Project | What it does | Focus |
| ------- | ------------ | ----- |
| [**AI Resume Screening & Ranking**](https://github.com/malkitchoudhary/AI-Resume-Screening-Candidate-Ranking-System) | NLP engine that scores resumes against job descriptions using TF-IDF similarity and outputs ranked shortlists | NLP + Ranking |
| [**Movie Recommender System**](https://github.com/malkitchoudhary/movie-recommender-system) | Content-based recommender served through FastAPI with precomputed similarity matrices | Recommenders + API |
| [**Research Paper Recommendation**](https://github.com/malkitchoudhary/Research-Paper-Recommendation) | Recommends relevant papers from abstracts via cosine similarity — no cold-start dependency | NLP + Search |
| [**Email Spam Detection API**](https://github.com/malkitchoudhary/email_spam_api) | Real-time spam/ham classifier exposed as a REST API | NLP + Deployment |
| [**Patient Record System**](https://github.com/malkitchoudhary/Patient-Record-System) | Healthcare data management for patient records, appointments, and treatment history | Healthcare + Data |
| **Skin Disease Multimodal Classifier** | Dual-branch CNN + tabular fusion on PAD-UFES-20 (TensorFlow/Keras), 75.39% test accuracy | Healthcare AI + DL |
